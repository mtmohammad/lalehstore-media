## طرز ساخت
1. اول یک استوری مرتبط بذار (مثلا استوری محصول روز).
2. روی پروفایل دکمه «+» (New) زیر بیو ← استوری رو انتخاب کن ← Next.
3. «Edit cover» ← آیکون عکس ← کاور مربوطه رو از گالری انتخاب کن (وسط دایره خودش درست قرار می گیره) ← اسم رو بنویس ← Done.
4. برای اضافه کردن استوری های بعدی: روی استوری بزن ← «Highlight» (پایین صفحه) ← هایلایت مورد نظر.
5. برای عوض کردن کاور هایلایت قبلی: روی هایلایت نگه دار ← Edit highlight ← Edit cover.

## نکته ها
- هر استوری که می ذاری همون روز به هایلایت مرتبطش اضافه کن، وگرنه بعد 24 ساعت گم می شه (از Archive هم می شه برگردوند).
- ترتیب هایلایت ها با آخرین استوری اضافه شده عوض می شه؛ برای اینکه «جدیدها» اول بمونه، آخر از همه به اون استوری اضافه کن.
- استوری های قدیمی/ناموجود رو از هایلایت ها پاک کن.

کاورها با `python3 -I tools/highlights.py highlights` ساخته می شن.
